# The three provided samples

These are the rate confirmations supplied with the exercise, converted to text
with `pdftotext -layout`. That is *not* byte-identical to what `pdf.py` produces
— it uses `pdfplumber` and inserts its own page separators — but it is the same
kind of artefact: layout-preserved text with the table columns still interleaved,
which is the property the pipeline has to survive.

They are committed as text rather than PDF because the text is what the pipeline
consumes and what a reviewer needs in order to check a claim about it. They are
synthetic documents generated by the UltraShip TMS itself — "test automation
pickup", "Playwright Driver", `testuser@ultraship.ai` — not customer freight.

`tests/test_provided_samples.py` runs all three end to end on every CI run. That
test is the answer to "does this work on *our* documents?", and it is the reason
these files are here rather than in `.gitignore`.
